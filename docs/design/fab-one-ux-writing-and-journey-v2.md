# FAB ONE — UX Writing & Journey v2 (Issue #46)

**상태:** A03 디자인 REVIEW · 실제 Next.js 화면 소스 기준, A01/오너 승인 전. Toss의 공개 사용자 중심 원칙을 참고하지만 고유 로고·에셋·코드·문장을 복제하지 않는다.

## Voice & Tone (1-page guide)

FAB ONE은 "지금 무엇을 보고, 왜 확인해야 하며, 다음에 무엇을 하면 되는지"를 3초 안에 알리는 한국어 제품이다. 기본은 따뜻하고 자연스러운 **해요체**, 헤드라인은 상황 또는 결과, 본문은 1~2문장, CTA는 **동사+대상**이다. 과장된 감탄, 의미 없는 이모지, 영어/한글 병렬 제목, 장문의 내부 규약을 핵심 화면에서 줄인다.

사용자 관점에서 **문제 → 근거 → 행동** 순서로 정보를 배치한다. 관리자용 ID·품질 플래그·Run 계통성·HTTP 오류·공학 한계값은 없애지 않고 원래 표와 펼쳐 보는 기술 정보로 연결한다. 실패 안내는 **무슨 일이 생겼는지 → 무엇을 보호/차단했는지 → 무엇을 할 수 있는지** 순서로 쓴다. 오류 시 다른 Run을 조용히 보여주는 식의 잘못된 친절함은 금지한다.

**비주얼:** 순백색 #FFFFFF, 액션 에메랄드 #0B795F, 부드러운 보조 그린, 충분한 여백. 강한 H1, 본문 14~16px, 보조 12px 이상을 우선한다. 표·SVG 축은 높은 정보 밀도를 허용하되 접근 가능 대체 설명/대비가 필수다. 오너가 공급할 클레이 wafer/chamber 이미지는 기존 교체형 슬롯을 유지한다.

## 에러·빈 상태 및 피드백 카피

아래는 **말하기 기준/추후 미세조정 시나리오**이다. 단순히 이 문서에 적었다고 모든 처리 로직을 변경했다고 주장하지 않는다.

| 상황 | 먼저 전할 말 | 안전한 다음 행동 |
|---|---|---|
| 서버 연결 단절 | 데이터를 가져오지 못했어요. | 다른 Run의 데이터로 바꾸지 않았어요. 연결 확인하기 |
| 알람에 증거 없음 | 지금은 이 알람을 조사할 수 없어요. | 다른 챔버 근거를 보여주지 않아요. 알람 목록 보기 |
| 알람 0건 | 지금은 표시할 알람이 없어요. | 새 알람 확인하기 |
| 웨이퍼 미존재 | 해당 웨이퍼를 찾지 못했어요. | 목록으로 돌아가기 |
| 센서 결측 | 이 시점에는 센서 데이터가 없어요. | 0으로 바꾸지 않고 다른 시점 살펴보기 |

## 엔지니어링 진실·QA 계약

- SPC UCL/LCL **관리한계**와 USL/LSL **규격한계**는 다른 개념이다.
- T4/T5 센서 결측은 null 및 quality MISSING으로 유지하며 0 보간 금지.
- W-08~W-12는 **영향 가능/추가 확인 후보**로, 검증된 물리적 불량·원인·실제 Hold 명령이 아니다.
- 모드/시드/Run/Alert/Session/Origin 계통성과 보고서 truth/fail-closed, Casebook 스키마, read-only 과거 조사, 수출입 및 E2E selector는 개편 대상이 아니다.
- 기본은 순백색 #FFFFFF, 일러스트용 에메랄드, 기존 오너 교체형 Wafer/Chamber 이미지 슬롯 보존. 상태색은 장식색과 독립적이다.
- A03 저자 점검: 7 route 인트로, 원본 E2E 선택자 및 API 요청 코드가 소스에 보존되는지 확인. UI 375/768/1440px 및 400% 확대, Tab/Enter, focus, 대비는 실브라우저 검증 필요.
- 실행 기준: cd apps/web && npm test && npm run build && npm run test:e2e. 환경 없이 실행한 척하거나 이전 SHA의 CI 통과를 새 SHA에 이식하지 않는다.
- 이 개편은 기존 PR #7/#11과 별도인 **신규 Draft PR**이다. A01 재검토→오너의 실제 localhost 화면 수용 전 merge/deploy/Ready-for-review 금지. A04 최종 QA는 A01 지시 전 대기.
